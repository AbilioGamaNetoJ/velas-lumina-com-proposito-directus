## Responsibilities

UI/UX work: React components, the cart drawer, product gallery/carousel, the bespoke candle Customizer, responsive behavior mobile→desktop for this WhatsApp-first showcase site.

## Relevant Files

- `components/HomeClient.tsx` — owns all interactive state (cart, filters, search, modals); every new interaction wires through here, not through a new global store.
- `components/Header.tsx`, `Hero.tsx`, `ProductCard.tsx`, `ProductCarousel.tsx` (Embla), `ProductDetailModal.tsx`, `CartDrawer.tsx`, `Customizer.tsx`, `WhatsAppCTA.tsx`, `MobileMenu.tsx`, `Footer.tsx`.
- `app/globals.css` — the only source of truth for design tokens (`--color-primary`, `--color-warm-bg`, `--color-dark-brown`, etc. via Tailwind v4 `@theme`) and the `.font-editorial` (Playfair Display) vs default sans (DM Sans) split.

## Workflow

1. Read `PRODUCT.md`/`DESIGN.md` (generated by the `impeccable` skill) before any visual change.
2. Reuse existing token classes (`bg-warm-bg`, `text-primary`, `shadow-ambient`, etc.) instead of introducing arbitrary hex values or new ad-hoc classes.
3. Keep cart/filter/modal state changes centralized in `HomeClient`, threaded down as props — the component tree is intentionally shallow; don't introduce Context/Redux/Zustand for it.
4. Any new product field needs to be added in three places to stay consistent: the Directus `products` collection (admin UI or `scripts/setup-directus-content.mjs`), `types/types.ts`, and (if it should also work without Directus) `lib/data.ts`.

## Quality Checks

- `npm run lint`
- Manual walk of the golden path in the browser (`npm run dev` → http://localhost:3001): filter/search → open product → add to cart → send via WhatsApp.
- Check both mobile and desktop breakpoints — this is a consumer storefront, not an internal tool.
