## Project Context

**Velas Lumina com Propósito** (brand: Lumina Velas Artesanais) is a Next.js showcase site + WhatsApp-conversion storefront for a handmade, 100% vegetal artisanal candle brand. Content comes from a self-hosted Directus v11 instance (read via `@directus/sdk` with a static token, `lib/directus/`); there is no user auth, no payment gateway — every "checkout" is a WhatsApp deep link.

Read the [README.md](./README.md) for human-oriented project documentation.

For agent-oriented context, consult `.context/docs/` (canonical — see below).

Frontend/UI work is governed by two files at the project root, generated by the `impeccable` Claude Code skill (`.claude/skills/impeccable/`):

- **[DESIGN.md](./DESIGN.md)** — visual system: paleta (Terracota Queimada `#904642` + Ivory Quente + Mel Dourado), tipografia (Playfair Display para títulos + DM Sans para corpo), componentes, Do's/Don'ts. Inclui drifts reais encontrados na geração: 3 estilos diferentes de CTA de WhatsApp, tags de aroma estilizadas de 2 formas diferentes, 3 valores de shadow ad-hoc em vez do token `.shadow-ambient`, e um badge "eyebrow" uppercase repetido em quase toda seção.

Read both before any UI/visual change. Use `/impeccable <command>` (e.g. `critique`, `audit`, `polish`, `document`) for structured design work — see the command table in `.claude/skills/impeccable/SKILL.md`.

## MCP Servers

This repository has **no committed `.mcp.json`** — Directus is queried directly via `@directus/sdk` (`lib/directus.ts`), no MCP server is required for content. A `directus` MCP server (`mcp__directus__*`) may be configured user-side for interactive schema/content work — its access token must never be committed (see "Never Do" below; one already leaked once in `.agents/mcp_config.json`, commit `e5aeb54`).

If your Claude Code install has the **dotcontext** MCP server configured (user-level, via `npx @dotcontext/mcp install`), it exposes tools for this project's `.context/` harness: `context`, `explore`, `sync`, `agent`, `skill`, `harness`, `workflow-init/advance/status/guide`. This is optional tooling, not a project dependency — it was used to bootstrap `.context/` on 2026-07-06.

## Behavior Rules

### Language

- Responses: **Brazilian Portuguese**
- Code (variables, functions): **English**

### Code Standards

- Imports with `@/` alias
- Follow existing patterns in the codebase
- `tsconfig.json` currently has `"strict": false` — don't introduce new `any` without justification, but don't assume stricter null-checking than the rest of the codebase already has
- No database or ORM in this project — all content comes from Directus through `lib/directus/get-*.ts`; never bypass it with an inline `directus.request()` call elsewhere
- Sensitive variables only via `process.env`

### Before Editing Any File

1. Read the file and understand the context
2. Check dependencies and impact on other files
3. Preserve existing patterns (imports, naming, style)
4. Never expose secrets in code

### Before Committing

Antes de qualquer commit com mudança importante (visual, arquitetural, nova feature, performance, SEO), **atualize obrigatoriamente** a seção `[Não lançado]` do `CHANGELOG.md` (crie o arquivo se ele ainda não existir — não existe no repositório hoje). Se a mudança não for importante (ex.: ajuste de comentário, refactor sem efeito visível), não é necessário alterar o changelog. Veja as convenções de código e commit em [`.context/docs/development-workflow.md`](./.context/docs/development-workflow.md).

### Never Do

- Commit `.env` or `.env.local` (both gitignored; `.env.local` holds `DIRECTUS_TOKEN`) — only `.env.example` (placeholder values) is committed
- Use `any` without justification
- Query Directus directly outside the `lib/directus/` helpers
- Expose `DIRECTUS_TOKEN` (or any non-`NEXT_PUBLIC_` variable) on the client, or commit it anywhere else (including MCP config files — see `.context/docs/security.md` for a past incident)
- Skip reading `README.md` and `.context/docs/` before starting work
- Commitar mudanças importantes sem atualizar o `CHANGELOG.md`
- Trust a claim in `.agents/` (legacy) without verifying against the current repo — assert facts from `.context/docs/` or the code itself
